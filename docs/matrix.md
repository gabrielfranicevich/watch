# Matrix community

To request an invitation to the ani-cli Matrix space, use the `#ani-cli-queue:matrix.org` room and select the option to knock/request access. In the reason field, say that you want to join the ani-cli community.

Not every Matrix client supports knocking. Use a client that supports it, such as Element or Nheko. Invitations may not be immediate.

For bug reports or feature requests, use the [GitHub issue tracker](https://github.com/gabrielfranicevich/anime/issues).
