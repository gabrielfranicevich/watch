# Upstream Matrix community

The ani-cli Matrix space and its invitation process belong to the original [pystardust/ani-cli project](https://github.com/pystardust/ani-cli) and its maintainers. This repository's Rust implementation is maintained separately; participation in the upstream community does not imply that its maintainers support or maintain this port.

For the current room and invitation steps, follow the [upstream Matrix instructions](https://github.com/pystardust/ani-cli/blob/master/matrix.md). Invitation timing and community access are managed by the upstream maintainers.

For defects or feature requests specific to this Rust implementation, use [this repository's issue tracker](https://github.com/gabrielfranicevich/anime/issues). For issues with the original shell project or its community, consult the [upstream repository](https://github.com/pystardust/ani-cli).
